# GoStack — ReactJS Concepts Challenge

A study project developed during the **Rocketseat GoStack** program to practice React fundamentals and frontend integration with a REST API.

> **Study project:** this repository follows the GoStack learning path and is preserved as part of my technical learning history.

## What the project does

The interface consumes the repositories API from the Node.js challenge and allows the user to manage repository items from the browser.

Main behaviors include:

- Load repositories from the backend
- Render the repository list
- Add a repository through the API
- Remove a repository through the API
- Update React state after API operations

## Tech stack

- React 16
- JavaScript
- Axios
- React Hooks
- React Testing Library
- Jest DOM
- Create React App

## Concepts practiced

- Functional React components
- `useState` and `useEffect`
- API consumption with Axios
- Rendering collections
- State updates after asynchronous operations
- Event handling
- Component testing

## Running the project

Install dependencies:

```bash
yarn
```

Start the development server:

```bash
yarn start
```

Run the tests:

```bash
yarn test
```

The application expects the related Node.js repositories API to be available according to the original course setup.

## Project context

Created in 2020 as part of Rocketseat's GoStack ReactJS fundamentals challenge. The implementation is intentionally kept close to the original study exercise to document the frontend technologies and concepts practiced at that point in my learning path.
